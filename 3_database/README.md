# PennyWise - Database Package

This package contains SQL scripts, database contracts, and JSON export data for PennyWise.

## Contents
- `schema_and_seed.sql`: Consolidated master SQL script containing full table creation DDL and seed records.
- `schema.sql`: Clean DDL for `categories`, `transactions`, `budgets`, `savings_goals`, and `user_settings`.
- `seed_data.sql`: Initial seed rows with 11 default categories, standard budgets, and sample transactions.
- `DATABASE_SCHEMA.sql`: Extended schema documentation with constraints and indexes.
- `DATABASE_CONTRACT.md`: Database schema specification and field constraints.
- `pennywise_db.json`: Live structured JSON store with all current database entities.
